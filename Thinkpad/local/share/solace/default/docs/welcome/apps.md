# Apps And Defaults

Walker is the launcher. Press `Super + Space` and type the app name.

## Defaults

Use `Solace Menu > Setup > Defaults` to set:

- default browser
- default terminal
- default editor

## Installing extras

Use `Solace Menu > Install` for optional browsers, editors, terminals, gaming
tools, web apps, TUI wrappers, and development environments.

## Removing extras

Use `Solace Menu > Remove` for optional apps you installed through the menu.
