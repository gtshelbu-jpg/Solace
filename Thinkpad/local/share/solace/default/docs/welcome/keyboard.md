# Keyboard And Navigation

Solace is designed to feel quick once a few bindings are in muscle memory.

## Core shortcuts

- `Super + Space`: app launcher
- `Super + K`: keybinding search
- `Super + Enter`: terminal
- `Super + Shift + F`: files
- `Super + Alt + Space`: Solace menu
- `Super + Escape`: system menu

## Finding anything else

Use `Super + K` whenever you forget a binding. The keybinding viewer is usually
faster than digging through config files.

The Waybar Solace icon opens the same menu as `Super + Alt + Space`.
