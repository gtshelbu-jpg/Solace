# Start Here

Welcome to Solace.

Solace is an Arch and Hyprland desktop shaped around fast keyboard navigation,
small focused tools, and a system menu that keeps the common stuff close by.

## The first five moves

- `Super + Space` opens Walker, the app launcher.
- `Super + Alt + Space` opens the Solace menu.
- `Super + K` searches keybindings.
- `Super + Enter` opens a terminal.
- `Super + Escape` opens power and session actions.

## What to try first

Open the Solace menu from Waybar or with `Super + Alt + Space`, then visit:

- `Setup` for audio, Wi-Fi, Bluetooth, monitors, defaults, and config files.
- `Install` for optional apps and developer tools.
- `Update` for system updates and service restarts.
- `Learn` to come back to this guide.
