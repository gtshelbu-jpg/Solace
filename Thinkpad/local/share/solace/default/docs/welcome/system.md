# System Care

Solace is still Arch underneath, so updates are normal Arch package updates plus
the Solace migration and cleanup steps.

## Update

Open `Solace Menu > Update > System`.

That path updates system packages, AUR packages, migrations, orphan cleanup, and
post-update hooks.

## Useful maintenance entries

- `Update > Config`: refresh selected config files back to defaults.
- `Update > Process`: restart desktop services like Waybar, Mako, Walker, and SwayOSD.
- `Update > Firmware`: update firmware when supported.
- `Setup > Config`: open editable config files.
